# ☁️ AWS S3 Presigned URL Generator (Node.js + TypeScript)

A simple and effective backend service to generate **presigned POST URLs** for uploading files directly to **AWS S3**, built with **Node.js** and **TypeScript**.

---

## 🔥 Features

- 🚀 Generate secure S3 presigned URLs
- 🧠 Built using AWS SDK v3
- 🛠️ Structured with TypeScript + Express
- 🧩 CORS and JSON middleware enabled
- ⚙️ Easy configuration via `.env` file

---

## 📦 Technologies Used

- Node.js
- TypeScript
- Express.js
- AWS SDK v3
- dotenv
